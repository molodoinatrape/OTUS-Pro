# Scoring API — ДЗ 06 и 08

Учебный HTTP API с валидацией запросов. Два метода: `online_score` — расчёт
оценки, `clients_interests` — получение интересов клиентов.

## Домашние задания и ветки

Один проект используется для двух домашних заданий. Версии решения разделены
ветками Git; рабочий каталог для обеих версий — `homeworks/06_08_API_scoring`.

| Домашнее задание | Ветка | Содержание |
|---|---|---|
| 06. ООП | `hw06-API_scoring` | Базовый API: описание полей, валидация, авторизация, скоринг и интересы клиентов |
| 08. Тестирование | `hw08-testing` | Развитие базового API: модульные тесты, параметризация и работа с хранилищем; в работе |

В ДЗ 08 код предыдущего задания развивается в том же каталоге. Для просмотра
базовой версии используется ветка `hw06-API_scoring`, для работы над тестированием
и хранилищем — `hw08-testing`.

### Что меняется в ДЗ 08

- Добавляются модульные тесты и запуск сценариев с разными наборами данных.
- В `store.py` реализуется клиент-серверное key-value хранилище с таймаутами
  и повторными подключениями.
- `get_score` получает зависимость `store` и использует кеш; недоступность кеша
  не должна мешать вычислению оценки.
- `get_interests` получает интересы из хранилища вместо случайного выбора;
  недоступность основного хранилища приводит к ошибке.
- Со звёздочкой добавляются интеграционные тесты с реальным хранилищем.

Это требования следующего этапа; реализация ДЗ 08 пока в работе.
Обновлённый учебный шаблон `scoring.py` отличается от базовой версии именно
обращениями к `store` и не заменяет рабочий модуль без адаптации его вызовов в API.

Базовая версия ДЗ 06 проверена на Python 3.14.3 и не требует внешних зависимостей.
Приведённые ниже команды относятся к существующей базовой реализации.

## Запуск

Команды выполняются из папки `homeworks/06_08_API_scoring`.

```sh
python api.py
```

По умолчанию сервер слушает `localhost:8080`, логи выводятся в консоль.
Другой порт и запись логов в файл:

```sh
python api.py -p 8081 -l api.log
```

## Тесты

```sh
python -m unittest discover -s tests -p "test.py" -v
```

## Запросы

Оба метода вызываются через `POST /method` с заголовком
`Content-Type: application/json`. Готовые запросы находятся в
[requests.http](tests/requests.http), их можно запускать через HTTP Client в PyCharm.

Токен обычного пользователя: `SHA-512(account + login + SALT)` в виде
шестнадцатеричной строки. Если `account` отсутствует, используется пустая строка.
Для `login=user` без `account`:

```sh
python -c "import hashlib; print(hashlib.sha512(b'userOtus').hexdigest())"
```

Подставьте результат в поле `token`:

```json
{
  "login": "user",
  "token": "<токен>",
  "method": "online_score",
  "arguments": {"phone": "79991234567", "email": "user@example.com"}
}
```

Ответ: `{"response": {"score": 3.0}, "code": 200}`.

Для интересов клиентов замените `method` на `clients_interests`, а `arguments`
на `{"client_ids": [1, 2]}`. Пример ответа:

```json
{"response": {"1": ["books", "music"], "2": ["sport", "travel"]}, "code": 200}
```

В базовой версии ДЗ 06 интересы выбираются случайно. Ошибки возвращаются в формате
`{"error": "<сообщение или словарь ошибок>", "code": 422}`.

Полное описание полей и правил ДЗ 06 — в [условии задания](docs/task.md).
